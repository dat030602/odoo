During the process of using the software, with the need to change the unit of measurement of products that have had purchase/sale/move of warehouse transactions, users who want to change the unit of measurement should follow these steps:

Step 1: At the product screen, click on "Execute > select Change unit of measurement"

The system will display a screen to update the calculation unit

Description of items:

  • 1, In this section, the user selects the storage unit that needs to be changed
  • 2, In this section, the user selects the purchasing unit that needs to be changed
  • 3, In case the sales order uses a different unit of calculation than the one previously configured on the product, the user needs to check here and select the unit of calculation to update on the sales order.
  • 4, In case the purchase order uses a different unit of calculation than the one previously configured on the product, the user needs to check here and select the unit of calculation to update on the purchase order.

*for example: product “Right corner table”
