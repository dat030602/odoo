Automated Open API v1 Sync

No manual CSV uploads required. dn_vn_address synchronizes directly from the official open administrative division endpoint:

  • Configurable Endpoint: Controlled via System Parameter dn_vn_address.api_url (Default: https://provinces.open-api.vn/api/).
  • Scheduled Cron: Background cron keeps administrative names, codes, and division types synchronized.
  • Idempotent Upsert: Matches on official GSO codes, ensuring existing contact addresses remain fully intact without duplicate records.
