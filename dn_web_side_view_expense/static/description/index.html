Web Side View

Speed up List View workflows with 3 display modes: Base, Split View, and Popup. The module helps you view and edit records faster without leaving the list.

Split View Popup View Local State

Compatible with Odoo 19 and installed automatically on top of the standard web module.

Key Features

Boost productivity on List Views with intuitive side-by-side and popup editing modes.

Split View

Display the list and form side by side. Click a record to open its form on the right panel while keeping the list in view for fast navigation.

Popup View

Open record forms in a lightweight modal dialog. Ideal for quick inspections or edits without leaving the current list context.

Local State Persistence

Your preferred display mode and panel width are automatically saved in the browser so the next session picks up right where you left off.

Configure Once, Use Effortlessly

No complex setup is required. The module integrates automatically into every List View. Users simply pick a display mode directly from the interface, and preferences are remembered for the next session.

Enterprise-Grade Performance

Lightweight and optimized for Odoo 19. Designed to maintain full responsiveness on desktop environments while keeping the standard Odoo List View experience intact.

  • Three display modes: Base, Split View, and Popup
  • No configuration required — works out of the box
  • Persists the last used mode and panel width per browser
  • Switch instantly between modes without reloading
  • Works seamlessly with standard Odoo List Views
  • Clean integration — no visible trace unless activated
