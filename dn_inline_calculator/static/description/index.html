How It Works

Type your formula, press Tab

This module seamlessly hooks into the native parse() function of Odoo 19's fundamental number field inputs. Whenever you blur the active element or hit Tab, the system interceptor validates the string expression, processes it into a calculated value, and suppresses native red-border validation warnings.

Key Features & Specifications:

  • Supports 4 fundamental operators: Addition (+), Subtraction (-), Multiplication (*), Division (/)
  • Supports grouping order of operations using parentheses: (100 + 50) * 2
  • Secure execution: strict regex sanitization isolates numbers and legitimate math tokens before parsing
  • Smart Fallback handler: gracefully defaults back to standard Odoo parser behaviors if the syntax is broken
