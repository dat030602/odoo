Inline Calculator for Fields

Allow users to type mathematical expressions directly into Float, Integer and Monetary fields. Expressions are automatically evaluated when the field loses focus, making data entry much faster without interrupting the normal Odoo workflow.

OWL Patch Auto Evaluation Float / Integer / Monetary Odoo 19

Compatible with Odoo 19 Community & Enterprise. Extends the native OWL number fields without modifying existing business logic.

Key Features

Perform calculations directly inside Odoo numeric fields.

Inline Math Expressions

Enter expressions like 100+50, 15*1.2, or (20+5)/2 directly into any supported numeric field.

Native OWL Integration

Seamlessly patches Float, Integer and Monetary fields without changing your existing views or business logic.

Safe Expression Parsing

Invalid formulas automatically fall back to the default Odoo parser while valid expressions are evaluated instantly.

Faster Data Entry

Stop switching between Odoo and an external calculator. Simply type the formula into the field and continue working. The result is calculated automatically after leaving the field.

Native OWL Component Patch

Built entirely with OWL component patching. No Python modifications, no view inheritance, and no database changes are required.

  • Supports Float fields
  • Supports Integer fields
  • Supports Monetary fields
  • Addition, subtraction, multiplication and division
  • Parentheses supported
  • Automatic evaluation on blur
  • Safe expression validation
  • Automatic fallback to Odoo parser
  • Lightweight OWL patch
  • No server-side changes
  • Works in Community & Enterprise
  • Easy installation
