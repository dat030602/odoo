Smart Search

Search records across multiple Odoo models from a single, keyboard-friendly search box. Instead of navigating through different menus, find and open any record instantly with score-ranked, highlighted results.

Global Search Cross-Model Keyboard Navigation OWL Component

Compatible with Odoo 19 and installed automatically on top of the standard web module.

Key Features

Find any record in seconds with a single search powered by smart scoring and cross-model indexing.

Global Cross-Model Search

Search across Sale Orders, Purchases, Invoices, Contacts, Tasks, Products and more — all from one search box, with results grouped and ranked by relevance.

Configurable Providers

Choose which models are searchable, define the fields and subtitles, set priorities and icons — all manageable from a clean List/Form configuration screen.

Keyboard Navigation

Open with Ctrl+K, navigate results with Arrow keys, jump to a record with Enter and close with Escape — fully optimized for keyboard-first workflows.

Global Search Dialog

Open the global search with Ctrl+K, type a few letters and open any record instantly. Results are highlighted, ranked and grouped by model.

Configure Once, Use Effortlessly

No complex setup is required. The module ships with sensible default configurations for Sale Orders, Purchases, Invoices, Contacts and more (created by the post-install hook). Users simply start typing, and preferences are remembered for the next session.

Lightning-Fast Results

Results are cached and ranked by a smart scoring algorithm that boosts contacts, orders and matching fields. Built as a lightweight OWL component optimized for Odoo 19, keeping the standard user interface experience intact.

  • Global search across multiple models from one box
  • No configuration required - works out of the box
  • Score-based ranking with smart keyword boosts
  • Keyboard-friendly navigation (Ctrl+K, arrows, Enter)
  • Works seamlessly with standard Odoo List Views
  • Matches highlighted and grouped by model
