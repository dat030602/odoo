Intelligent Storage & Versioning

When clicking Save in the spreadsheet editor, users can control how revisions are retained:

Option A: Overwrite Original
Updates the existing ir.attachment directly in-place without altering attachment IDs or external references.
Option B: Save as New Version
Generates a new attachment with smart incremental naming (e.g. quotation (v2).xlsx) linked to the active record.
User Preference Setting:

Users can configure their default preference in My Preferences → Excel Editor Save Mode: Ask every time, Always overwrite, or Always create new version.

Security & Macro Sanitization

Protecting enterprise ERP deployments against malicious macro payloads and zip-based vulnerabilities:

Automatic Macro Stripping
When saving .xlsm files, embedded VBA binary parts (vbaProject.bin) are stripped and the file is securely exported as clean .xlsx.
Zip-Bomb & Traversal Guard
Strict server-side validation rejects malformed zip entries, traversal sequences (../), and decompressed files exceeding memory limits.
Strict Access Rights:

Editing and saving requires write permissions on the underlying attachment record. Read-only permissions trigger view-only mode automatically.
