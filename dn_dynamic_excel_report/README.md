# Dynamic Excel Report Framework

## Overview

The Dynamic Excel Report Framework provides a low-code approach for generating Excel reports in Odoo. Instead of writing Excel generation logic for every report, developers only need to provide a method that returns the report data as an array of objects. The framework will render the Excel file based on configurable layouts and mappings.

## Features

- **Low-Code Configuration**: Configure reports through Odoo views without coding
- **Reusable Templates**: Create and reuse report templates
- **Flexible Layouts**: Configure header, body, and footer sections
- **Rich Formatting**: Comprehensive cell formatting options
- **Column Configuration**: Independent column settings with summary support
- **Multi-Layout Reports**: Add multiple body sections before main table
- **Header Merging**: Merge table header cells for grouping
- **Column Summaries**: Automatic sum, average, min, max, count summaries
- **Developer-Friendly**: Simple data provider interface

## Installation

### Prerequisites

- Odoo 19.0 or higher
- Python dependencies: `xlsxwriter`, `xlrd`
- Base `report_xlsx` module from OCA

### Installation Steps

1. Copy the module to your Odoo addons directory
2. Update your addons path in `odoo.conf`
3. Restart Odoo server
4. Install the module via Apps menu

## Configuration

### 1. Create Cell Formats

Navigate to **Excel Reports** → **Configuration** → **Cell Formats** and create reusable cell formats:
- Font settings (family, size, bold, italic, color)
- Alignment (horizontal, vertical, wrap text)
- Background colors and patterns
- Borders (left, right, top, bottom)
- Number formats (currency, date, percentage, custom)
- Protection settings

### 2. Create Layouts

Navigate to **Excel Reports** → **Configuration** → **Layouts** and create reusable layouts:
- Header layouts (company info, report title, date)
- Body layouts (summary cards, information blocks)
- Footer layouts (signatures, terms, generated by)

### 3. Create Templates

Navigate to **Excel Reports** → **Configuration** → **Report Templates** and create templates:
- Define default header, body, and footer layouts
- Set default column configurations
- Configure default settings (sheet name, file pattern, etc.)

### 4. Create Reports

Navigate to **Excel Reports** → **Reports** and create reports:
- Select target model and data provider
- Choose template or configure from scratch
- Configure header, body, and footer layouts
- Set up table columns with formatting
- Configure summary options

## Developer Guide

### Creating a Data Provider

Create a class that inherits from `excel.report.abstract`:

```python
from odoo import models, api

class MyReportProvider(models.AbstractModel):
    _name = 'excel.report.my_report'
    _inherit = 'excel.report.abstract'
    _description = 'My Report Provider'

    @api.model
    def get_report_data(self, records, context=None):
        """
        Return report data as list of dictionaries.
        
        Args:
            records: Odoo recordset to report on
            context: Optional context dictionary
            
        Returns:
            List of dictionaries with report data
        """
        data = []
        for record in records:
            data.append({
                'field1': record.field1,
                'field2': record.field2,
                'calculated': record.field1 * record.field2,
            })
        return data
```

### Register Report Configuration

Create an XML record to register the report:

```xml
<record id="excel_report_my_report" model="excel.report">
    <field name="name">My Excel Report</field>
    <field name="code">my_report</field>
    <field name="model_id" ref="base.model_my_model"/>
    <field name="provider">excel.report.my_report</field>
    <field name="state">published</field>
</record>
```

## User Guide

### Running Reports

1. **From Menu**: Navigate to **Excel Reports** → **Reports**, select report, configure filters, click "Export Excel"
2. **From Records**: Open target model, select records, click "Action" → "Export to Excel"
3. **Preview**: Use "Preview" button to test report with sample data

### Configuring Columns

For each column in your report:
- Set display name and field name
- Configure width and alignment
- Assign cell formats (header, data, summary)
- Set data type for proper formatting
- Configure summary type (sum, avg, min, max, count)
- Configure header merging if needed

### Using Variables

In layout cells, you can use variables:
- `company_name`: Company name
- `report_name`: Report name
- `current_date`: Current date
- `current_time`: Current time
- `user_name`: Current user name
- `timestamp`: Current timestamp
- `record_count`: Number of records
