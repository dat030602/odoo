Web Side View

Speed up List View workflows with 3 display modes: Base, Split View, and Popup. The module helps you view and edit records faster without leaving the list.

Split View Popup View Local State

Compatible with Odoo 19 and installed automatically on top of the standard web module.

Default

Keep the standard Odoo behavior

Users can switch back to the default Base mode at any time whenever they want to follow the standard Odoo flow.

Split View

List on the left, form on the right

Click a record to open its form next to the list. This is ideal when you need to review, compare, or edit multiple records in a row.

Popup View

Open forms in a lightweight dialog

Perfect for quick actions without disrupting the current list context.

Setup

Install and use, no complex configuration required

The module integrates automatically into the system List View. Users choose a display mode directly in the interface, and the last state is stored locally for the next session.

Key features

  • Switch quickly between Base, Split View, and Popup.
  • Preserve the native Odoo List View experience.
  • Remember the interface state and panel width in the browser.
  • Work smoothly on desktop screens without reloading the page.
