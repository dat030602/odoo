How It Works

Configure Once, Generate Flawlessly

This module operates as a core backend Abstract Engine. When functional business modules pass structured data (either as an Odoo Recordset or a List of Dictionaries) alongside a valid template code, the engine securely maps data keys, applies layout definitions, handles calculations, and streams back a production-ready Base64 Excel string.

Key Technical Specifications:

  • Python Function Registry: Execute custom Python strings on raw fields dynamically (e.g., upper casing, sanitization, or conditional text manipulation) before rendering.
  • Smart Print Setup: Pre-configured layout rules handling automatic landscape orientation, standard A4 paper formatting, and strict padding margins (0.3 to 0.5 inches).
  • Formula & Media Integration: Fluidly renders functional Excel cell operations starting with = and safely converts Base64 images directly via native sheet embedding (embed_image).
  • Extensible Hooks: Features standard base lifecycle hooks including _render_header and _render_footer allowing downstream business modules to inherit and append corporate identity.
