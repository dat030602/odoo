# Inventory Commitment Dashboard

## Overview
Provides a centralized, one-stop view for warehouse managers to track exactly which Sales Orders and Deliveries are reserving current stock, and when incoming replenishments are expected.

## Key Features
* **One-Stop Dashboard:** Replaces the need for multiple clicks across different screens. View Actual Stock, Reserved Stock, and Available Stock side-by-side.
* **Drill-down Capabilities:** Instantly view the specific Sales Orders and Picking documents tying up inventory.
* **Incoming ETA Tracking:** Displays quantities in transit from Purchase Orders alongside their expected arrival dates.
* **Quick Release:** Allows warehouse managers to select low-priority reservations and release them instantly to free up stock for other orders.

## Usage
Navigate to **Inventory > Commitments** to access the dashboard. Use the pivot and list views to analyze stock bottlenecks.
