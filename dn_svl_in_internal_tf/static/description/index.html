Automated Workflow

How It Works in 4 Steps

Operates transparently in the background of your daily inventory operations without altering standard warehouse staff processes:

Step 1

Configure Settings

Navigate to Inventory > Settings. Enable Internal Transfer Valuation and select move types (Receipts, Deliveries, Transfers) for SVL and Journal Entry generation.

Step 2

Validate Operation

Warehouse operators process transfers, vendor receipts, or customer deliveries as normal. When the picking reaches the Done state, our hook triggers automatically.

Step 3

Auto-Post Accounting

The system generates valuation layers with exact unit costs. If inter-warehouse valuation accounts differ, a balanced account.move is generated and posted immediately.

Step 4

360° Traceability

Auditors and accountants navigate seamlessly between pickings, valuation layers, and journal entries with one-click bidirectional smart buttons across all views.

Smart Fallback

Multi-Tier Valuation Account Resolution

Avoid configuration bottlenecks. When moving goods between locations, the system resolves the stock valuation account using a clean 3-tier hierarchical lookup:

Tier 1 • Direct Location Account
Location Specific

Checks the dn_valuation_account_id configured directly on the internal warehouse location form.

Tier 2 • Recursive Hierarchy
Parent Warehouse Lookup

If empty, automatically walks up the location tree (e.g. Rack > Zone > Warehouse) to inherit from the parent location.

Tier 3 • Category Fallback
Product Category Property

If no location account is set in the hierarchy, falls back smoothly to property_stock_valuation_account_id.
